# 워드프로세서 문제은행과 검수 기록

## 실제 등록 수

기본 JSON `src/data/questions.json`에는 ID·정규화 본문·보기 중복 검사 후 **1,000개**의 자체 제작 내부 검토 문항이 등록되어 있다. 부족 **0개**. 기존 120개 전체 객체(ID·문제·보기·정답·해설·메타데이터)는 변경하지 않고 880개를 추가했다. 개인 로컬 등록분과 검증 대기 문항은 포함하지 않는다.

| 현재 학습 과목 | 개념·사례형 | 계산 조건 변형 | 합계 |
| --- | ---: | ---: | ---: |
| 워드프로세싱 용어 및 기능 | 140 | 200 | 340 |
| PC 운영체제 | 140 | 200 | 340 |
| PC 기본상식 | 140 | 180 | 320 |
| 합계 | 420 | 580 | 1,000 |

원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 숫자 조건 변형은 **29유형 × 20조건 = 580개**이며 전체의 58%다. 1,000개 기출이나 1,000개 독립 개념을 뜻하지 않는다. 420개 개념·사례형도 서로 관련된 기능과 개념을 다룬다. 기존 진법 예제 2개는 개념·사례형에 포함하고 추가 대량 조건 변형은 family로 구별했다.

## 개념·사례형 범위

기존 120개 + 신규 과목별100개, 총420개. 문서 편집·서식·문단·구역·표·개체·메일 머지·인쇄·협업·접근성, Windows 창·파일·권한·장치·서비스·네트워크·접근성·백업·복구, 하드웨어·문자·이미지·음성·네트워크·보안·개인정보·스프레드시트·데이터베이스 등이다.

원고는 `scripts/concepts.tsv`와 `scripts/expanded-concepts.tsv`. AI의 일반 지식으로 자체 작성했으며 읽지 않은 교재나 공식 자료를 정답 증빙으로 인용하지 않았다. 각 문항의 sourceUrl은 이 작성·검수 기록의 위치이고 외부 정답 증빙이 아니다. 출제 연도·회차는 모두 null이다.

내부 내용 검토는 작성자가 문제의 조건, 정답 하나와 오답 세 개의 구별, 답과 해설의 일치, 일반화 범위를 확인한 것이다. Windows 문항은 제품/버전 차이가 있는 부분을 문맥과 해설에 한정했다. 보안 기능이 사실성·완전한 안전을 보증하지 않는 점과 PDF/암호화/숨김/읽기 전용/동기화/백업의 차이를 확인했다. 법령의 미확인 수치·개정일·공식 회차는 추가하지 않았다.

## 계산 조건 변형

각 family의 20개 조건은 고정된 정수 입력으로 생성한다. 임의 시드나 외부 API를 사용하지 않는다. 총29개 유형의 정확한 ID·등록 수·서로 다른 입력 수는 [BANK_AUDIT.json](BANK_AUDIT.json)에 기록한다.

| 과목 | 계산 유형 | 조건 수 |
| --- | --- | ---: |
| 워드프로세싱 | 본문 가로 폭·세로 높이, 다단 폭, 표 열 폭, 첫 줄 좌표, 고정 행의 쪽 수, 단면 부수, 양면 부별 용지 수, 인쇄 배율과 글자 크기, 화소 수와 인쇄 폭 | 각20 / 200 |
| PC 운영체제 | 파일 크기 합, KiB 변환, 클러스터 수, 남는 클러스터 공간, 볼륨 여유량, 전체+증분 백업량, 일정 복사율의 시간, 압축 후 크기, 페이지 수, 예약 작업 경과 시간 | 각20 / 200 |
| PC 기본상식 | 이진수·십육진수 해석, 비트 패턴 수, 비트율과 전송 시간, RGB 데이터량, PCM 데이터량, 스캔 픽셀 수, UTF-8 데이터량, 8비트 반전 | 각20 / 180 |

각 문항에 `family`, `calculation.kind/values/result/unit/precision`를 기록한다. 문제에 가정·입력·단위·필요한 소수 표시 규칙을 명시하고, 해설에 식·대입·단위와 결과를 적었다. 클러스터의 압축/희소/상주 데이터, 그림의 헤더/패딩, 음성의 압축, 파일 복사의 지연 등은 문제에 명시한 범위에서만 제외한다. 실제 시스템의 관측치나 공식 출제 분포를 재현한 것이 아니다.

작성 경로 `scripts/numeric_bank.py`는 Python Fraction의 정확한 유리수 연산을 사용한다. 검증은 이를 import하지 않는 `tests/numeric-bank.test.ts`에서 역산, 블록 할당 시뮬레이션, 비트 반전, 실제 UTF-8 TextEncoder, 문제에 표시된 이진/십육진 문자열 파싱 등으로 수행한다. 580조건 모두의 정답 번호·단위·수치 동치 보기·표시 정밀도·해설 결과를 검사한다. 수치 검증과 해설의 문장·개념 검토, 외부 전문가 검수는 서로 다르다.

실전 추출에서는 family를 먼저 묶어 가능한 한 같은 family에서 한 문항만 뽑는다. 과목별140개 개념·사례형과 9~10개 수치 family가 있어 현재 기본 은행은 한 회 과목별20개를 서로 다른 그룹에서 뽑기에 충분하다. 사용자 로컬 은행 등에서 그룹이 부족하면 고유 ID로 보충하는 기존 정책은 유지한다.

## 중복 및 의미 검토

ID와 NFKC·공백·대소문자 정규화 본문+정렬된 보기, 정규화 본문 단독 중복은 모두0이다. 보기 순서만 바꾼 문항을 추가하지 않았다. 420개 개념·사례형의 같은 과목 내 문자열 유사도 0.58 이상 후보 **71쌍**을 추출해 내부 검토했다. cd/dir, IPv4/IPv6, 증분/차등 백업, 위/아래 첨자, Ctrl/Shift 선택처럼 질문 대상과 정답이 다른 대조 개념은 유지했다. 문자열 유사도는 의미를 자동 판정하지 않으며 71쌍 이외의 모든 의미 중복 부재를 증명하지도 않는다.

수치 family의 조건 변형은 의도적으로 관련된 문항이며 독립 개념으로 세지 않는다. 이들은 동일 조건의 중복을 제거한 실제 등록 문항 수에 포함한다. 단순 문장·이름 치환으로 개념 수를 늘렸다고 주장하지 않는다.

## 검수 한계와 권리

`reviewed`는 **작성자의 내부 내용 검토와 명시된 자동 검사**를 통과한 상태다. 외부 전문가의 독립 검수, 현행 공식 과목명·지정 운영체제·출제기준 항목별 대조는 미완료다. 공식 자료 요청이 차단된 기존 상태를 확인 완료로 바꾸지 않았다. [시험 규칙 확인 상태](EXAM_RULES.md).

자체 제작 원고·생성 문항은 CC BY 4.0. 표시: Word-Processor-CBT contributors, 이 저장소 링크, https://creativecommons.org/licenses/by/4.0/ 및 변경 사항. 타인의 원문·보기·이미지를 대량 복제하지 않았다. AI 보조 작성물의 저작권 성립 여부는 관할에 따라 다를 수 있으며 제3자 권리를 허락하는 것은 아니다.

기출 재배포에는 원문·정답·연도·회차·이용 조건 확인이 필요하다. 공개 접근이나 출처 표시만으로 허락을 추정하지 않았다. 적법한 기출을 확보하지 못했다는 것은 기출이 존재하지 않는다는 뜻이 아니다.

## 재현과 확장

```sh
python3 scripts/generate_bank.py
python3 scripts/audit_bank.py
npm test
```

원고 순서·ID·정답 배치를 고정하고 재생성 동일성 및 기존120개 전체 SHA-256 검사를 남겼다. 감사 JSON에는 현재 은행 파일의 SHA-256과 유형·과목·중복 후보 수를 기록한다. 기본 데이터를 늘릴 때도 기존 풀이 기록의 ID 참조를 보존한다.

가져오기는 이 브라우저에만 저장되며 pending으로 시작한다. 근거를 입력하고 로컬 승인한 뒤 학습에 포함되며 GitHub 공용 은행에 자동 게시되지 않는다.
