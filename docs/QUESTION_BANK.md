# 워드프로세서 문제은행과 검수 기록

## 실제 등록 수

중복 제거 후 기본 JSON `src/data/questions.json`에 등록된 자체 제작 내부 검토 문항은 **120개**다. 목표 1,000개에서 **880개 부족**하므로 최종 수량 기준은 충족하지 않는다. 사용자 개인 로컬 등록분은 포함하지 않는다.

| 학습 과목 | 개수 |
| --- | ---: |
| 워드프로세싱 용어 및 기능 | 40 |
| PC 운영체제 | 40 |
| PC 기본상식 | 40 |
| 합계 | 120 |

원문 기출 0, 복원 0, 자체 제작 120. 숫자 조건 변형 0, 숫자 변형 family 0. 진법 변환 개념 예제 2개는 조건별 대량 변형이 아니다. 검증 대기 0, 제외된 전기기능사 문항 900개는 처음부터 가져오지 않았다.

## 작성과 실제 검토 범위

`AI의 일반 지식`에 기반해 원고 `scripts/concepts.tsv`를 직접 작성했다. 외부 교재나 확인하지 않은 공식 자료를 문항의 정답 증빙으로 인용하지 않았다. 각 문항의 sourceUrl은 이 작성·검수 기록의 위치이며 외부 증빙이 아니다. 출제 연도와 회차는 모두 null이다.

내부 검토: 문제 조건, 정답과 오답 3개의 구별, 해설과 정답의 일치, 일반화 범위를 문항별로 검토했다. Windows 단축키는 파일 탐색기 등 해당 문맥을 한정하고 버전·설정에 따른 차이를 해설에 적었다. 절전/최대절전, PDF의 보안 한계, 파일 확장자 변경과 형식 변환, HTTPS와 사이트 신뢰성, 동기화와 백업을 구분했다. 진법 예제는 자릿값 합으로 재계산했다(1010₂=8+2=10, 15=8+4+2+1=1111₂).

자동 검사: ID와 NFKC·공백 정규화 본문+정렬된 보기 지문, 보기 개수·중복, 정답 범위, 출처·권리·검토 메타데이터, 재생성 동일성. 자동 검사가 정답의 사실성이나 모든 의미 중복을 증명하지는 않는다.

의미 검토: 복사/이동, 절전/최대절전, 각주/미주, 첫 줄 들여쓰기/내어쓰기 등 유사 쌍은 구별 개념을 학습하기 위해 남겼다. 120개가 120개의 완전히 독립된 개념이라는 뜻은 아니다. 외부 전문가의 독립 검수, 공식 출제기준과의 항목별 대조, 최신 Windows 지정 버전 대조는 **미완료**다. `reviewed`는 내부 검토 상태이며 이 한계를 문항별 reviewNote에도 기록했다.

## 문항 권리

새 자체 제작 원고·JSON은 CC BY 4.0으로 제공한다. 표시: Word-Processor-CBT contributors, 이 저장소 링크, 라이선스 https://creativecommons.org/licenses/by/4.0/, 변경 사항 표시. 타인의 문제 원문·보기·이미지를 복제하지 않았다. AI 보조 작성물의 저작권 성립 여부는 관할에 따라 다를 수 있으며 제3자 권리를 허락하는 것은 아니다.

원문 기출 수록은 원문·정답·연도·회차·재배포 허락 확인이 필요하다. 공개 웹사이트 접근 가능성만으로 재배포 허락을 추정하지 않는다. 이번에는 재배포 조건이 확인된 기출을 확보하지 못했다. 기출이 존재하지 않는다는 뜻은 아니다.

## 재현과 확장

`python3 scripts/generate_bank.py`는 고정 원고 순서·ID·정답 순환 배치로 동일한 JSON과 가져오기 양식을 생성한다. 랜덤 시드는 사용하지 않는다. 출처·검수 대기 문항이나 의미 없는 숫자 치환으로 수량을 채우지 않았다. 기존 ID를 보존하며 새 개념과 적법한 기출을 추가 검토해야 한다.

가져오기는 이 브라우저에만 저장되며 무조건 pending으로 시작한다. 근거를 입력하고 로컬 승인한 뒤 학습에 포함된다. GitHub 기본 문제은행으로 자동 게시되지 않는다.
